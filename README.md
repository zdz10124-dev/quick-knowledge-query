# 快速知识查询

一个面向 Windows 的快捷 AI 查询小工具，使用 DeepSeek V4.1 Flash。支持文字快问、框选截图和固定区域截图，并用置顶小窗流式显示答案。

## 独特的上下文机制

先装载固定知识 `A`。之后每次查询都独立请求：

- 问 `B`：发送 `A + B`
- 再问 `C`：发送 `A + C`

上一轮的问题和回答不会进入下一轮，因此不会像普通连续对话那样让历史上下文不断变长。对于“围绕同一批资料反复查问题”的场景，可以明显减少重复携带聊天历史产生的 token 消耗。

## 输出长度

系统提示词只要求模型**尽量简洁、通常控制在约 100 个汉字以内**，不是硬截断。

API 另有 `max_output_tokens` 上限，默认是 **400**，可在 `config.json` 中修改。

## 使用

首次使用可在应用内填写 DeepSeek API Key；若存在环境变量 `DEEPSEEK_API_KEY`，会自动读取。

默认快捷键：

- `Ctrl+Alt+1`：文字快问
- `Ctrl+Alt+2`：框选截图
- `Ctrl+Alt+3`：固定区域截图
